# NEXORA NEXUS

**NEXORA NEXUS** est une application professionnelle de gestion d'entreprise (ERP) moderne, robuste, évolutive, sécurisée et conçue avec une approche **offline-first**.

Elle repose sur l'architecture centrale **NEXORA CORE**, permettant à la plateforme de gérer la multi-tenancy, l'authentification, la sécurité et la synchronisation de données tout en accueillant d'autres modules futurs.
